# Python QR Code Generator & Scanner

## Description
This is a Python-based QR code project that allows users to **generate** and **scan** QR codes.  
The project is designed to demonstrate practical use of **Python programming**, **OpenCV**, and **pyzbar** for QR code applications.

## Status
⚠️ Work in Progress  
The project is currently under development and has not yet been fully tested.

## Features (Planned)
- Generate QR codes from any text or URL
- Decode QR codes from images or webcam input
- Save generated QR codes as image files
- User-friendly interface (console-based or GUI planned)

## Requirements
- Python 3.x
- `opencv-python`
- `pyzbar`
- `qrcode` (for QR code generation)
